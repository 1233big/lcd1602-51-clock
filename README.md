# lcd1602-51-clock

AT89C52 + LCD1602 电子时钟（Keil C51）。上电后第一行显示 `Clock`，第二行从 `23:59:55` 开始走时，
用定时器 0 产生秒基准，不依赖 RTC 芯片，适合作为 8051 定时器与字符屏驱动的入门示例。

## 功能

- 定时器 0 方式 1，12 MHz 下 1 ms 中断（`TH0 = 0xFC`、`TL0 = 0x18`），中断里软件计满 1000 次进位 1 秒
- 时/分/秒逐级进位：秒满 60 → 分 +1，分满 60 → 时 +1，时满 24 → 归 0
- 初值 `23:59:55`，上电后几秒就能看到进位
- 只在秒值变化时整行重写时间，避免高频刷新造成闪烁
- 附带可复用的 LCD1602 并行驱动：光标定位、写字符 / 字符串、定宽补零显示数字

## 硬件接线

| LCD1602 引脚 | 接到 |
|---|---|
| D0 ~ D7 | P0.0 ~ P0.7 |
| RS | P2.6 |
| RW | P2.5 |
| E | P2.7 |
| V0（对比度） | 电位器中间脚 |

注意：P2.5 ~ P2.7 在开发板上同时接着 LED6 ~ LED8，写屏时这三颗灯会跟着闪，属正常现象。
P0 口是开漏输出，板上需要有上拉电阻（常见开发板已自带）。

## 驱动接口

`lcd1602.h` 暴露以下函数，调用前必须先执行一次 `LCD_Init()`：

| 函数 | 作用 |
|---|---|
| `LCD_Init()` | 上电初始化：等 40 ms → 8 位两行 → 开显示关光标 → 清屏 → 光标右移 |
| `LCD_Clear()` | 清屏并回到左上角 |
| `LCD_SetCursor(row, col)` | 光标定位，`row` 取 0/1，`col` 取 0 ~ 15 |
| `LCD_WriteChar(c)` | 在当前光标处写一个字符 |
| `LCD_WriteString(str)` | 从当前光标处写字符串 |
| `LCD_WriteStringAt(row, col, str)` | 定位后写字符串（最常用） |
| `LCD_WriteNum(num)` | 写无符号整数（不补位） |
| `LCD_WriteNumAt(row, col, num, width)` | 定宽显示，位数不足左边补 0 |

驱动不做忙标志检测，全部用固定延时（E 保持约 5 µs、每条指令后等约 40 µs），延时按 12 MHz 估算。

## 快速开始

**1. 编译（Keil C51）**

在 Keil 中打开 `LCD1602.uvproj`，按 `F7` 或菜单 `Project → Build Target`，生成的 `作业.hex` 位于 `Objects/` 目录。

**2. 烧写**

用对应烧写工具把 `Objects/作业.hex` 写入芯片：AT89C52 需要编程器，STC89C52 可以用串口 ISP 工具下载。

**3. 运行自检（可选，不需要硬件）**

`build_lcd.py` 是一个只实现本项目用到指令的 8051 编码器 + LCD 总线模拟器，
它把汇编逻辑编码成 hex，并在模拟器里逐个指令执行，把 E 下降沿时刻 P0 上的字节打印出来，
最后断言 LCD 收到的指令序列和显示文本符合预期：

```bash
python -I tools/build_lcd.py
```

正常情况下输出末尾为：

```
commands: 38 38 0C 01 06 80 C0
lines on LCD: ['Claude', 'LCD1602 OK']
checks OK
```

这个脚本演示的是显示固定字符串的最简版本（对应 `docs/lcd1602_demo.asm`），
时钟逻辑以 `src/main.c` 为准。

脚本会把编码结果写到**与它同目录**的 `lcd1602.hex`，该文件已被 `.gitignore` 忽略。
它和 Keil 编译出的 `Objects/作业.hex` 是两个不同的东西：前者用于离线自检，后者才是烧进芯片的固件。

## 注意事项

- 定时初值按 **12 MHz** 晶振计算。若板子实际用的是 11.0592 MHz，1 ms 会变成约 1.085 ms，
  走时偏慢约 8.5%（约合每天慢 2 小时），需要重算初值或调整 `main.c` 中 `flag` 的阈值。
- 时钟只在 `sec` 变化时重写第二行，因此 `hour` / `min` 的进位只在秒进位的那一帧体现。
- 显示函数不会自动擦除旧字符，位数变短时要整行重写或先用空格覆盖。

## 开发约定

- 源文件使用 UTF-8 编码、LF 换行
- C51 源码 4 空格缩进，函数上方用块注释写明「作用 / 参数 / 用法」
- 新增驱动函数先在 `lcd1602.h` 声明，再在 `lcd1602.c` 实现
- 提交信息用动词开头，说清为什么改
